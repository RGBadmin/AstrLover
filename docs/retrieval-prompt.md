# 检索造词提示词

跟视觉解析提示词配套：**那份决定库里存的是什么词，这份决定拿什么词去搜。**
两份不对齐，索引建得再好也搜不出来。

- 提示词正文：面板 →「设置」→「相册」→ **检索造词提示词**（可改，改完即时生效）
- 默认值在 `astrlover/album/prompts.py`
- 用在 `want_photo`：她只说"为什么想发"，由轻量模型照这份把它翻成检索词
- 输出格式（`keywords` / `want` / `rating` / `season`）由 `tools.py` 追加，
  不在可编辑的那份里——调提示词是常事，调坏解析就白瞎一次调用

## 里面是三样东西

**词汇表**，按环境 / 衣着 / 身体 / 动作体液 / 拍法分好——跟索引侧的三段向量（env / body / act）是同一套划分。词面检索是 IDF 加分制
不取交集（`album/search.py`），多给词只影响排序不会搜不到，所以提示词让她
一次给六到十个、三类各给几个。

**同义词表**：他的说法 → 库里的词。库里写的是「骚逼」，搜「下面」一张都出不来——
实测还会被拆字回退成「面」，捞回一堆无关的图。

**情境预测**：此刻的词，加上等下的词。她在家化妆准备上班、他问今天穿的什么、
她说等下出门了拍给你——此刻是「卧室 梳妆台 化妆 睡衣」，等下是「室外 马路
全身镜 站姿 穿搭」，**两组都给**。

预测是补充不是替换：化妆是真实上下文，该留着；漏掉「出门以后」那组才是错。
词面不取交集，两组一起给谁都不漏——实测三张（化妆 / 街拍 / 车里）全能捞到，
只给一组就各丢一半。

## 分词词典要跟着一起对齐

检索侧分词拿 `TAG_VOCAB` 做正向最大匹配：在词典里的整体切出来，不在的退二元
滑窗，「蝴蝶逼」会被切成「蝴蝶」「蝶逼」，命中率差一大截。

词典原先只从标签候选值凑，缺三类词，都补进 `vision/tags.py` 了：

- **裸词**——候选值里只有「淫水拉丝」这种复合形态，可正文写的、人搜的都是「淫水」
- **场景与拍法**——「酒店」「全身镜」「站姿」正文里天天出现，候选值里却没有对应项
- **组合说法**——「双腿大开」拆开只剩「腿」，没有区分度

还修了分词器一个真 bug：字母和汉字是分开扫的，`M腿大开`、`T恤` 这种混排词
永远匹配不上——字母那半太短被丢掉，剩下的汉字又不成词。现在整段先查一次词典。

691 → 785 词。

**改视觉提示词的用词时，这三处要一起看：** 视觉提示词、`tag_schema.py` 的候选值、
`tags.py` 的补充词表。`tests/test_search_prompt.py` 会验证提示词里教的词确实
切得出来——脱节了测试会挂，不会悄悄失效。
